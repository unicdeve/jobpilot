# Claude Code Project Instructions

Use `AGENTS.md` as the canonical project instruction set.

Before making changes:

- Read @AGENTS.md
- Read @.agents/SETUP.md
- Read the relevant product, architecture, and feature documents.
- Inspect existing code before implementing.

Follow the repository's acceptance criteria and Definition of Done.

Do not make architectural changes silently. If implementation requires changing
an accepted decision, stop and propose an ADR/update first.
