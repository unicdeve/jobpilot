# Connector Source Priorities

## MVP priority

- Public ATS/job board endpoints where practical
- Greenhouse
- Lever
- Workable or similar stable public source
- RSS/feeds
- Generic custom job URL analysis

## Post-MVP

- Authenticated job sites
- Browser-based sources
- User-installed third-party connectors

## Rule

Do not assume a site permits automated access. Respect applicable terms, technical restrictions, and user-controlled sessions.
