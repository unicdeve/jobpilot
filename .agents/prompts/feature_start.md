# Feature Start Prompt

Implement the requested feature from its specification.

Before coding:
- read the feature specification
- read relevant architecture docs
- read relevant rules/skill
- inspect existing code
- identify acceptance criteria
- identify core tests
- propose an implementation plan

Do not change accepted architecture without first proposing an ADR/update.

After implementation:
- run relevant tests
- verify every acceptance criterion
- report files changed
- report tests run
- report any unresolved issues
